# Visual AI Coding

Visual AI Coding 用图形界面统一管理 Claude Code 与 Codex 的配置、插件、Skill 和本地工具状态。

## 核心用途

- 集中查看 AI 编程工具的安装和运行状态。
- 管理配置文件、插件版本与 Skill。
- 在一个桌面界面中维护多种本地 AI 编程工具。
