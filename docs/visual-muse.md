# Visual Muse

Visual Muse 用于维护文章草稿、预览内容和管理发布配置，帮助内容创作者在发布前完成统一检查。

## 核心用途

- 编辑内容并预览 Markdown。
- 检查标题、摘要、正文与平台配置。
- 预览移动端内容卡片并维护本地发布状态。
