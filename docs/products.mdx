## Visual Worktree

以任务为单位管理多个 Git 仓库与 Worktree，集中查看分支状态、执行批量操作并组织跨仓库开发流程。

- **适合你，如果：** 经常同时维护多个仓库，希望把分支、Worktree、任务流程和环境检查放在一个界面中。
- **核心能力：** 项目扫描、批量 Git 操作、任务化 Worktree、研发流程和环境健康检查。
- **平台：** macOS 与 Windows。

## Visual AI Coding

用图形界面统一管理 Claude Code 与 Codex 的配置、插件、Skill 和本地工具状态。

- **适合你，如果：** 同时使用多种 AI 编程工具，希望集中查看安装状态、配置文件与插件版本。
- **核心能力：** 工具探测、配置编辑、插件更新、Skill 浏览和应用偏好管理。
- **平台：** macOS 与 Windows。

[查看源码](https://github.com/imberZsk/visual-ai-coding) · [下载最新版本](https://github.com/imberZsk/visual-ai-coding/releases/latest)

## Visual Lark Bridge

将飞书消息桥接到本机 Claude Code，并通过流式交互卡片展示执行状态、工具进度与回答内容。

- **适合你，如果：** 希望从飞书发起本机 AI 编程任务，并持续查看任务状态与结果。
- **核心能力：** 消息与媒体桥接、流式卡片、多轮会话、多任务管理和本地运行数据管理。
- **平台：** macOS。

[查看源码](https://github.com/imberZsk/visual-lark-bridge) · [下载最新版本](https://github.com/imberZsk/visual-lark-bridge/releases/latest)

## Visual Learn

扫描本地 Markdown 学习资料，在桌面应用内阅读文章、记录完成进度并维护标注与总结。

- **适合你，如果：** 本地保存了大量 Markdown 笔记，希望获得稳定的阅读与进度管理体验。
- **核心能力：** 资料扫描、Markdown 阅读、进度追踪、文章标注、总结和本地工具跳转。
- **平台：** macOS 与 Windows。

[查看源码](https://github.com/imberZsk/visual-learn) · [下载最新版本](https://github.com/imberZsk/visual-learn/releases/latest)

## Visual Muse

面向多平台内容创作与发布准备的桌面工作台，用于维护文章草稿、预览内容和管理发布配置。

- **适合你，如果：** 需要集中整理内容，并在发布前检查标题、摘要、正文与平台配置。
- **核心能力：** 内容编辑、Markdown 预览、移动端卡片预览、发布配置与本地状态管理。
- **平台：** macOS 与 Windows。
