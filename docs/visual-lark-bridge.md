# Visual Lark Bridge

Visual Lark Bridge 将飞书消息桥接到本机 Claude Code，并通过流式交互卡片展示执行状态、工具进度与回答内容。

## 核心用途

- 从飞书发起本机 AI 编程任务。
- 通过流式卡片持续查看任务状态与结果。
- 管理多轮会话、媒体消息和本地运行数据。
